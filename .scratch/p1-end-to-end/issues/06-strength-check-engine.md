# 06: 强度校核引擎：声明式规则 + 单元×铺层×准则 + 自然格聚合 + 危险部位

**What to build:** 强度分析工程师用声明式规则（YAML/JSON）指定材料/区域对应的失效准则、许用值来源、安全系数、MS 阈值、section point 选择与聚合规则；**确定性引擎**对每个单元 × 每个铺层 × 每种准则计算 FI（施加/许用）与 MS（许用/施加−1），每个单元取其最差铺层，再**按自然格聚合取该格最差单元**，自动定位**危险部位**（FI 最大 / MS 最小）。不连续格排除出自然格级校核但仍在单元级校核，并在结果中显式列出。规则版本纳入血缘。
