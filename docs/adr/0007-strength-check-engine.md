# 强度校核为确定性引擎：声明式规则 + 单元×铺层×准则遍历 + 自然格聚合

校核规则以 YAML/JSON 声明（材料/区域→准则、许用值来源、安全系数、MS 阈值、section point 选择、聚合规则），由 **L0 确定性引擎**执行：对每个单元×每个铺层×每种准则算 FI/MS，单元取最差铺层，再**按自然格聚合取该格最差单元**，输出明细表与判定。准则库含 Max Stress/Strain、Tsai-Hill、Tsai-Wu、Hashin(取 Abaqus 输出)，可扩展。

## Consequences

- 规则版本纳入血缘；改规则=新版本，不覆盖旧结果。
- LLM 不参与 FI/MS 计算与合格判定，只做规则草案与结果解释（见 ADR-0002）。
