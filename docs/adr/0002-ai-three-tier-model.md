# AI 采用 L0/L1/L2 三层职责模型，强度判定保留在确定性层

平台统一为三层职责：**L0 确定性层**（规则、脚本、优化求解器，可复现）、**L1 AI 辅助层**（生成候选、预测、排序、解释、在 FE 模型上标注，人可否决）、**L2 人类决策门**（设计选型、校核规则确认、优化方案批准、报告签发）。所有 AI 输出必须可解释、可回退、全程留痕。

## Consequences

- 关键约束：**失效指数/安全裕度的计算与强度合格判定永不由 LLM 完成**；LLM 只在已抽取的结构化数据上做解释、编排与标注。
- 理由：强度判定需可复现、可审计，LLM 不满足确定性要求。

## Considered Options

- 让 LLM 直接读取结果并判定强度：被否决——不可复现、不可审计，且 LLM 无法原生读二进制 ODB。
