# 自然格是平台一等公民数据，由结构拓扑模型生成而非从网格反推

自然格（相邻长桁与相邻肋围合的连续传力蒙皮区）是强度校核与报告的最小结构分区单元。平台显式维护**结构拓扑模型**（长桁线×肋线→自然格，赋予稳定 ID），并建立 **FE 网格单元 → 自然格** 的空间归属映射，使"逐单元"与"逐自然格"两级校核都能自动执行且可追溯，而不是从裸网格事后反推分区。

## 非张量半格的处置

当长桁终止(runout)、蒙皮开口(cutout)、部分肋(partial rib)等造成无法由四边连续长桁/肋围合时，该候选格**不构成自然格**：平台将其标记为 **"不连续格"**，**排除出自然格级校核**（单元级校核照常执行），并在强度报告中显式列出，同时把"该处结构如何处理"作为 **L2 人工决策项**推给人。AI 不擅自拆分/合并结构。

## Consequences

- 自然格 ID 跨模型版本需稳定映射，是报告与优化对比的基础。
- 拓扑模型来自 CATIA 几何派生，不手改几何；拓扑变更走模板换版流程。
- "不连续格"清单是报告与追溯的固定产物，不可静默丢弃。
- 自然格算法须显式做连续性校验（已验证：见 `prototype/natural-bay/`）。
