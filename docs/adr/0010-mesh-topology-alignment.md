# 网格划分必须与结构拓扑（长桁/肋线）对齐，禁止跨界自由网格作为交付网格

自然格按"单元×铺层×准则 → 自然格聚合"做强度判定，若 FE 单元跨越自然格边界，边界格的极值可能被错误归属。故规定：**交付的 FE 网格必须沿长桁线与肋线切分，跨自然格边界的不一致单元不得作为最终网格**。这约束了网格策略——采用以结构拓扑为硬边界的结构化/映射网格，而非无约束自由网格；自由网格仅可用于非校核区或过渡区，并须在交付前重新切分对齐。

## Consequences

- 网格生成器必须以结构拓扑模型（长桁/肋线）为切分输入，二者耦合；拓扑变更需重新切分。
- 好处：自然格归属唯一、无歧义，报告可追溯；坏处：复杂几何区域网格自由度下降，需局部过渡处理。
- 与 ADR-0008（自然格一等公民）、ADR-0007（强度引擎）直接配套。

## Considered Options

- 形心归属自由网格：实现最简单，但边界格极值可能取错，强度判定不可靠，否决。
- 保守包络（跨界单元计入相邻两格）：更保守但会让同一单元重复计入、报告口径复杂，作为网格无法完全对齐时的兜底而非首选。
