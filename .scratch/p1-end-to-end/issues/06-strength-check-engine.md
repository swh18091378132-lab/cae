# 06: 强度校核引擎：声明式规则 + 单元×铺层×准则 + 自然格聚合 + 危险部位

**What to build:** 强度分析工程师用声明式规则（JSON）指定材料/区域对应的失效准则、许用值、安全系数、MS 阈值、section point 与聚合规则；**确定性引擎**对每个单元 × 每个铺层 × 每种准则计算 FI 与 MS，每个单元取其最差铺层，再**按自然格聚合取该格最差单元**，自动定位**危险部位**。不连续格排除出自然格级校核但仍在单元级校核。规则版本纳入血缘。

## 关键修正（自测暴露）

初版 Tsai-Wu 把 FI 误算成"应力缩放系数"，导致**非单调**（应力增大 FI 反而减小），且热点排序错乱。已改为标准口径：
```
b·t² + a·t − 1 = 0   (t = 使应力放大到失效的系数)
FI = 1/t = 2b / (−a + √(a²+4b))
```
修正后单轴验证 FI(s11=Xt)=1、FI(s11=−Xc)=1，且随应力单调递增。

## 验证结果
