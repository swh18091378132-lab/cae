## What to build

强度校核报告进入**多角色审批流程**。角色：设计、强度分析、审核、签发。报告状态机：`分析中 → 待审核 → 通过/退回 → 已签发`。审核人员可「通过」或「退回」并填写意见；**只有通过审核的报告才允许签发**，签发后成为最终版。

**关键合规点**：重跑产生新版本报告时，审批状态必须重置为「待审核」——旧审批绝不能继承到新内容上。所有状态变更记入 L2 决策审计（谁、何时、什么决定、理由）。

## Acceptance criteria

- [ ] 报告具备审批状态，状态机合法/非法转换被明确区分（非法转换被拒绝并给出原因）
- [ ] 审核可通过或退回，必须可填写意见；退回意见可被查询
- [ ] **未通过审核的报告不允许签发**
- [ ] 签发后报告标记为最终版，不可再改
- [ ] **重跑产生新报告版本时审批状态重置为待审核**（有测试断言）
- [ ] 所有状态变更记入 L2 决策审计（角色、动作、理由、时间）
- [ ] 可按角色查询待处理列表（如审核人员的待审清单）
- [ ] 服务层可独立单测，不依赖 UI
- [ ] Python 3.8 兼容
