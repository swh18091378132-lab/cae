# 01: 数据与追溯底座（Study / 血缘 / 不可变版本 / 决策日志）

**What to build:** 工程师能新建一个分析任务（Study），把一次分析产生的各类产物（参数集、数模、拓扑、网格、求解输入、结果、抽取、校核规则、校核结果、报告）按各自类型归入该 Study；每类产物只增版本、永不覆盖，任何两个产物之间的派生关系（血缘 DAG）可记录并打印；对"规则确认""报告签发"这类人类决策，记录谁、何时、依据什么。这是全平台可追溯性的地基。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent（已完成）

- [x] 建 Study 并落库
- [x] 产物按 (study, kind) 独立版本号递增，重复追加不覆盖
- [x] 产物内容不可变（尝试改写内容字段会被拒绝），仅状态可变更
- [x] 血缘边（parent→child）可记录，可按拓扑顺序打印
- [x] L2 决策日志记录 gate / actor / decision / rationale / 时间
- [x] 产物指纹为 sha256，相同内容得到稳定指纹
