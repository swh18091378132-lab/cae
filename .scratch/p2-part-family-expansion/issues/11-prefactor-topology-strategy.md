## What to build

结构拓扑生成不再是「机翼盒段专用代码」，而是**按模板声明的布置规则生成**：模板声明自己是翼面类（长桁×肋围合自然格）还是筒段类（桁条×框围合自然格），拓扑模块据此生成结构拓扑与自然格。

**机翼盒段行为必须完全不变**——硬约束：自然格总数 30、四类场景的失效格 ID 与数量（runout 4 格 / 开口 1 格 / 部分肋 6 格）逐项与原实现一致。改完后尾翼与机身只要各自声明布置规则即可复用同一套拓扑引擎。

## Acceptance criteria

- [ ] 模板可声明拓扑模式（翼面类 / 筒段类）及布置规则，新增族无需改拓扑代码
- [ ] 机翼盒段零回归：自然格数、四类场景失效格 ID 与数量与原实现逐项一致
- [ ] 不连续格（长桁终止 / 开口 / 部分肋）识别与标记保持有效
- [ ] 自然格稳定 ID 可重复（同参数集两次生成一致）
- [ ] 筒段类拓扑可生成（桁条×框围合），有单测覆盖
- [ ] 纯算法模块，可脱离 CATIA/Abaqus 独立单测
- [ ] Python 3.8 兼容
