## What to build

工程师选「尾翼盒段」，填入该族参数（前后梁位置、翼肋数、翼展、弦长等，含操纵面切口），平台产出参数化数模 → 结构拓扑与自然格 → 有限元模型 → 求解 → 结果抽取 → 强度校核 → 强度校核报告，全链跑通并留下完整血缘。

尾翼与机翼同为翼面类但结构特征不同（前后梁位置不固定、可能有操纵面切口），本票验证「换族只要换模板 + 布置规则」这个抽象成立。

## Acceptance criteria

- [ ] 模板列表可选到尾翼盒段，能读取其参数契约与参数化包络
- [ ] 给定合法参数集，跑通建模→拓扑→FE→求解→抽取→校核→报告全链（fake 适配器）
- [ ] 自然格按尾翼布置规则生成，数量与规则一致；操纵面切口造成的不连续格被正确标记
- [ ] 参数越界/未知参数按参数契约被拒绝，且不落半成品产物
- [ ] 血缘链完整（参数集→数模→拓扑→网格→inp→odb→抽取→校核结果→报告）
- [ ] 报告可由该 Study 的校核结果生成并携带产物指纹
- [ ] Python 3.8 兼容
