## What to build

工程师在**全机总体层级**输入总体参数（翼展、机身长、尾容量等），平台据此**自动分解**出机翼、尾翼、机身各自的参数集，并把三个部件的 Study 关联到同一个型号配置下。型号配置表达「全机 → 部件」的层级关系，使血缘能够跨部件追溯。

本票只做「总体参数 → 部件参数集 → 建 Study 并关联」，不要求跑完所有部件分析（下一票负责）。

## Acceptance criteria

- [ ] 可创建型号配置并记录其总体参数
- [ ] 给定全机总体参数，能自动分解出各部件参数集，且各参数集满足对应模板的参数契约
- [ ] 各部件 Study 可关联到同一型号配置，父子层级可查询
- [ ] 分解规则可配置/可测试（给定总体参数断言分解结果）
- [ ] 数据库演进**不破坏 P1 既有数据**（新增表/列，旧 Study 仍可用）
- [ ] 层级关系可被血缘查询使用
- [ ] Python 3.8 兼容
