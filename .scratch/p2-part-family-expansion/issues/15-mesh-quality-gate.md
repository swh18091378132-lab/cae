# 15: 网格质量门与自动加密（不破坏拓扑对齐）

## Parent

Part of #9

## What to build

网格生成后自动评估**网格质量**：每个自然格给出畸变度、长宽比、翘曲度等指标；对超标的自然格**自动加密重划**，直到达标或达到加密上限。加密后仍须保证**每个单元唯一归属一个自然格**——ADR-0010 的硬约束，不能因加密出现跨自然格边界的单元。

无法达标的自然格要给出明确警告并记录在案，使报告中能体现结论的适用边界。

## Acceptance criteria

- [ ] 可计算每个自然格的网格质量指标（至少：畸变度、长宽比、翘曲度）
- [ ] 指标计算有单测覆盖（构造已知质量好/坏的网格，断言数值正确）
- [ ] 超标自然格可自动加密重划，且**加密后单元仍唯一归属一个自然格**（跨界单元数为 0）
- [ ] 达到加密上限仍不达标时产生明确警告并在产物中留痕
- [ ] 可关闭自动加密（仅出质量报告），行为可配置
- [ ] 机翼盒段既有网格行为在默认策略下不回归
- [ ] Python 3.8 兼容
