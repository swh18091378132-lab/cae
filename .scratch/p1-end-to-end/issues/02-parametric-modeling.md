# 02: 参数化建模：模板参数契约 + CATIA 驱动再生

**What to build:** 工程师给定一组具名参数（展长、后掠、弦长、肋数、桁条数等），平台先按该结构族模板的**参数契约**与**参数化包络**校验（未知参数、越界、跨参数约束一律拒绝并给出可读原因），通过后驱动 CATIA 按参数集再生**参数化数模**，并把参数集与数模（含指纹）记入血缘。再生失败时不产生数模产物，只报错。

**Blocked by:** 01

**Status:** ready-for-agent（已完成于 fake 层；真机 CATIA 待现场版本确认）

- [x] 模板以 JSON 声明参数契约（名字/类型/范围/默认/几何映射）与包络约束
- [x] 校验：未知参数、类型错误、越界、跨参数包络约束均被拒绝
- [x] 缺省参数自动补默认值
- [x] 通过校验后驱动 CATIA 再生数模并记录参数版本与数模指纹
- [x] 参数集→数模的血缘边正确
- [x] 重跑生成新版本，不覆盖旧版本
