# 19: 审批流与型号汇总接入工作台

## Parent

Part of #9

## What to build

把审批流与型号汇总接入本地工作台：审核人员能看到**待审列表**，点开可查看该报告的完整血缘与校核明细，做出「通过/退回」并填意见；签发人员只能对**已通过审核**的报告执行签发；项目负责人能在型号汇总视图里看到各部件报告处于哪个流程环节。

## Acceptance criteria

- [ ] 工作台可展示待审/待签发列表，并按角色区分可见操作
- [ ] 审核操作界面能看到报告对应血缘与校核明细，据此做出通过/退回
- [ ] 签发入口只对已通过审核的报告可用（未通过的不可签发）
- [ ] 型号汇总视图展示各部件报告的流程状态
- [ ] 工作台逻辑放在服务层，可脱离 UI 单测
- [ ] UI 冒烟可构造并销毁，Python 3.8 兼容
