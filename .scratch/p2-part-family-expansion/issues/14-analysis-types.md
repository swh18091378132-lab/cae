## What to build

强度分析工程师在任一部族上可选择**分析类型**：静力 / 模态 / 屈曲之外，增加**接触**、**非线性**（材料或几何）、**Explicit**（显式动力学，用于冲击与后屈曲）。不同分析类型在 Abaqus 侧产出不同分析步与接触定义，但**抽取结果格式保持一致**——后续强度校核逻辑不需要按分析类型分支。

本票在尾翼盒段上先验证这条路径（避免同时引入「新部件族」与「新分析类型」两个变量）。

## Acceptance criteria

- [ ] 分析类型作为可选项暴露，至少覆盖静力/模态/屈曲/接触/非线性/Explicit
- [ ] 接触可声明接触对；非线性可声明材料或几何非线性；Explicit 可声明时间步与质量缩放
- [ ] Abaqus 适配器求解接口对 fake 与 real 保持同签名，fake 对每种分析类型给出确定性结果
- [ ] **不同分析类型的抽取结果格式一致**（同字段同口径），校核逻辑无需按类型分支
- [ ] Abaqus 侧脚本继续通过 Python 2.7 兼容检查
- [ ] 至少在尾翼盒段上跑通一种新增分析类型的端到端闭环（fake 层）
- [ ] 真机探测到 Abaqus 时跑一次非静力分析；探测不到则显式 SKIP
- [ ] Python 3.8 兼容
