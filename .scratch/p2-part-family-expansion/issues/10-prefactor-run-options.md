## Parent

Part of #9

## What to build

工程师调用编排入口时不再需要记住 31 个位置参数。把编排入口改为「必需参数 + 一个选项对象」：Study 标识、参数集、模板、CATIA 适配器、数据库连接仍为必需；其余（各阶段的开关与目录、分析类型、网格策略等）收进一个带默认值的选项对象。

**对外行为完全不变**：现有 9 个测试全部保持通过，P1 的端到端链路、血缘结构、产物内容逐项一致。

这是为 P2 后续能力腾出扩展空间的前置改造——不改它，后面每张票都要往已膨胀的签名里继续塞参数。

## Acceptance criteria

- [ ] 编排入口收敛为「少量必需参数 + 选项对象」，选项对象有合理默认值（不传即可跑通 P1 全链）
- [ ] 现有全部测试（m0–m8）在不修改断言的前提下通过
- [ ] P1 端到端行为不变：产物种类、血缘父子关系、报告内容一致
- [ ] 新增一个选项字段不需要改动编排函数签名
- [ ] 本地工作台服务层与 CLI 同步适配，`main.py run` 仍可一条命令跑通
- [ ] Python 3.8 兼容（无 3.9+ 语法）
