# 17: 型号级汇总视图：多部件批量运行与结论汇总

## Parent

Part of #9

## What to build

项目负责人在型号配置下一键跑通全部部件（机翼 / 尾翼 / 机身），并看到**型号级汇总视图**：每个部件的最新最大失效指数 FI、最小安全裕度 MS、是否合格、以及当前流程状态。某部件改参重跑后，汇总自动反映最新结论。

## Acceptance criteria

- [ ] 可对型号配置下多个部件一次性编排运行（fake 适配器可确定性回归）
- [ ] 汇总视图给出每部件：最大 FI、最小 MS、合格判定、流程状态
- [ ] 汇总取各部件**最新版本**的校核结论（改参重跑后自动更新）
- [ ] 单部件失败不影响其他部件，失败原因在汇总中可见
- [ ] 汇总结果可被工作台服务层查询（供后续 UI 使用）
- [ ] Python 3.8 兼容
