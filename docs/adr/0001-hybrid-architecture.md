# 采用本地工程工作台 + Web 协作端的混合架构

CATIA V5R18 与 Abaqus 6.13-4 都绑定本机许可证与算力：CATIA 无免许可 headless，必须驱动本机已授权实例；Abaqus 依赖本机 FLEXnet token。因此建模与求解必须在本地进程内编排。而项目、任务、报告、审批、看板与多人协作天然适合 Web。故平台分为**本地工程工作台**（厚客户端：CATIA/Abaqus 编排、建模、求解、结果抽取）与**Web 协作端**（项目/任务/报告/看板/审批/追溯展示），两者通过项目数据契约通信。

## Consequences

- 本地工作台是唯一能触碰 CATIA/Abaqus 的组件，Web 端不得直接调用桌面软件。
- 追溯与报告依赖两者之间的数据契约保持稳定。
