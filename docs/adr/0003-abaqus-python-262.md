# Abaqus 侧脚本按内置 Python 2.6.2 兼容设计

Abaqus 6.13 内置 Python 为 **2.6.2**（2.7.3 自 6.14/2016 起才引入）。因此 Abaqus 侧所有脚本、结果抽取器与序列化格式必须使用 2.6.2 兼容语法，不得依赖 2.7 及以上才有的库特性；与平台宿主进程的通信须采用 JSON/CSV 等中性文本交换，避免跨解释器对象传递。

## Consequences

- 编写 Abaqus 脚本前先以 `abaqus python` 打印版本核对现场补丁。
- 现代 Python 语法（如 f-string、dict 推导的部分用法等）在目标环境会直接失败，代码审查须把关。
