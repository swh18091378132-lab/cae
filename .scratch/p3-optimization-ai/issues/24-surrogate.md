## What to build

用已评估的设计点拟合代理模型，**只用于候选排序与下一轮选点建议**。
这是 ADR-0002 的硬约束：代理模型是 L1 辅助，**不得宣告任何合格判定**。

新建 `core/surrogate.py`（纯算法、零第三方依赖）：

- **拟合**：在已评估点上做回归，预测目标值。样本不足时**明确拒绝拟合**并说明需要多少点
  （不能拿 3 个点拟合出假模型）。
- **只输出排序与建议**：返回结构的字段设计上**就不存在"合格/不合格"的位置**——
  这是靠数据结构本身保证的，不是靠注释约定。可行与否永远由确定性校核说了算。
- **必须能被实测对照并报误差**：给出误差指标（如留一交叉验证的 MAE/RMSE 之类），
  让使用者知道它在这批数据上到底靠不靠谱。
- **误差不达标即降级**：返回"不可用"并说明原因，调用方据此退化为"不排序"而不阻塞闭环。
- 平台无 numpy 依赖（`core/` 至今纯标准库），所以用最小二乘/简单回归即可，不要引入第三方。
- 需要能区分**几何变量与铺层变量**的量纲差异（缩放），否则数值大的变量会主导拟合。

## Acceptance criteria

- [ ] 在已知关系的数据集上，排序正确（断言代理模型把实际更好的点排在前面）
- [ ] 报出误差指标，且该指标能被独立复算
- [ ] 样本不足时明确返回"不可用"并说明所需最少样本数
- [ ] 误差超标时返回"不可用"，调用方可据此降级
- [ ] **返回值结构中不存在任何合格判定字段**（单测直接断言字段集合）
- [ ] 代理模型的建议与实际评估结果在数据上可区分（来源标记），供汇总视图展示
- [ ] 不引入第三方依赖（纯标准库）
- [ ] Python 3.8 兼容
